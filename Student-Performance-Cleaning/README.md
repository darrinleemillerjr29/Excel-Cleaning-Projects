PROJECT SUMMARY

This project analyzes a student performance dataset containing 1,000 raw records with demographics, study habits, and academic scores across four subjects. The primary challenges addressed were data cleaning (reducing to 741 validated records), calculating performance metrics, and creating visual dashboards to identify trends by grade, gender, and major. Skills demonstrated include data validation, Excel formulas (COUNTIF, AVERAGEIF, SUMIFS), pivot-style aggregations, conditional formatting, and chart visualization. The final output is a comprehensive analysis workbook with cleaned data, an executive dashboard, grade analysis, and cross-major comparisons.

📊 STUDENT PERFORMANCE ANALYSIS WORKBOOK

OVERVIEW
This workbook provides a comprehensive analysis of student academic performance across 741 students. It includes raw data, cleaned datasets, grade distributions, and comparative analyses by major and gender.

WORKBOOK STRUCTURE

📋 Sheet 1: Student_Performance_Raw
Contains the original dataset with 1,000 student records and 21 variables including demographics, study habits, lifestyle factors, and academic scores across 4 subjects (Math, Science, Language, History).

📋 Sheet 2: Student_Performance_Clean
Cleaned dataset formatted as an Excel Table ('StudentPerformance') with 741 validated records and 10 key columns: Name, Age, Gender, Major, subject scores, Average Score, and Grade.

📋 Sheet 3: Summary Dashboard
Executive summary with key metrics, grade distribution pie chart, and students by major bar chart. Highlights: 741 students, average age 21.5, overall average score 70.6.

📋 Sheet 4: Grade Analysis
Detailed grade breakdowns including distribution statistics (A: 6.9%, B: 47.5%, C: 39.7%, D: 5.9%), gender comparisons, and grades by major with stacked bar visualization.

📋 Sheet 5: Major Comparison
Cross-major analysis showing student distribution, average scores, subject performance, gender breakdown, and grade distribution across Arts, STEM, Business, and Humanities.

KEY FINDINGS
• Grade B is most common (47.5%), followed by C (39.7%)
• STEM has the highest enrollment (253 students, 34.1%)
• Humanities shows highest average score (71.3)
• Language scores highest overall (72.6 avg)
• Gender distribution is nearly balanced (368 male, 373 female)

DATA DICTIONARY
Grade Scale: A (85-100), B (70-84), C (55-69), D (41-54)
Majors: Arts, STEM, Business, Humanities
Subject Scores: Math, Science, Language, History (0-100 scale)
